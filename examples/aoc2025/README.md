# Advent of Code 2025 in Thunky

Ten days, one file each. Every solution states the puzzle, the answer it
produces, and how it works; each reads its input on standard input and prints
both parts as a 2-tuple.

```sh
thunky examples/aoc2025/aoc01.th < aoc01.txt
```

**The puzzle inputs are not in this repository.** Advent of Code asks that
inputs not be republished, so `examples/aoc2025/*.txt` is gitignored. Download
your own from [adventofcode.com](https://adventofcode.com/2025) and drop them
here as `aoc01.txt` … `aoc10.txt`; the commands in each file's header then work
as written. Inputs are per-account, so the answers recorded in the comments are
for the author's and will not match yours.

| Day | Puzzle |
|-----|--------|
| [1](aoc01.th) | A hundred-position dial: how many turns land on zero, and how many pass it |
| [2](aoc02.th) | The invalid ids in a list of ranges |
| [3](aoc03.th) | Banks of batteries, one bank per line |
| [4](aoc04.th) | Rolls of paper on a grid |
| [5](aoc05.th) | The kitchen's inventory database |
| [6](aoc06.th) | The cephalopods' arithmetic worksheet |
| [7](aoc07.th) | The tachyon manifold |
| [8](aoc08.th) | Junction boxes in 3D, joined shortest pair first |
| [9](aoc09.th) | Red tiles at the corners of a rectilinear loop |
| [10](aoc10.th) | Indicator lights and toggle buttons |

Unlike the [Euler](../euler/README.md) and [Rosetta](../rosetta/README.md)
sets, these are not in the playground's example picker: without its input a
solution has nothing to run on.
